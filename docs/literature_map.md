# Literature Map

This page is the Sphinx-facing index into the project bibliography and benchmark records.

## What It Contains

- `literature/lit_review.md`: the living evidence map.
- `literature/library.bib`: the BibTeX source library.
- `literature/benchmarks/tss_benchmark_records.csv`: machine-readable anchors for terminal-solubility and related records.
- `literature/benchmarks/provenance_map.md`: row-by-row source traceability.

## Why It Matters

The manuscript and the scientific foundation docs should not introduce claims that are not backed by this literature map. If the evidence changes, the paper outline and the scientific docs must change too.

## Working Rule

- Add new claims to the literature map before they become narrative claims in the manuscript blueprint.
- Keep DOI-backed sources in the BibTeX library.
- Preserve extraction provenance when a numeric anchor is copied into downstream docs or tables.
